# NeuroAdapt

## Topic
AI-powered adaptive exam preparation focused on retrieval practice, error diagnosis, and memory retention.

## Project Summary
NeuroAdapt helps students move from passive studying to active recall under realistic pressure.
It combines a concept web, mixed-format quizzes, flash rounds, and adaptive feedback to improve exam performance.

## Core Capabilities
- Concept web visualization with dependency-aware progression
- Multi-format question sessions (free-text, MCQ, numeric, multi-step, symbolic, teachback)
- Error-type classification (careless, procedural, conceptual, fatigue)
- Flash rounds for timed pressure training
- Spaced review and adaptive study pathways
- AI-assisted tutor and translation support

## Stack
- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion
- Supabase

## Status
Frontend is implemented and actively iterating. API and AI flows are integrated with ongoing reliability and UX improvements.
